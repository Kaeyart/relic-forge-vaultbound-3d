# Patch 35 — Progression Mega Patch

This combines the next progression work into one large patch:

- Ascendancy combat/runtime hooks
- Class starter build support for Sorceress, Warrior, Huntress
- Warrior and Huntress active skill data additions
- Atlas passive tree skeleton
- Atlas passive UI panel
- Progression validation report
- Map activity reward hooks for Atlas passives

Controls:
- P: Passive Tree
- O: Ascendancy
- Atlas Passives: sidebar panel button once panel root refreshes
- F9: print progression validation report

Testing:
1. Boot game.
2. Press P and allocate passives.
3. Press O, choose an ascendancy, allocate nodes.
4. Use class switching/testing from passive UI if available.
5. Press K and confirm class starter gems exist after fresh save / class switch.
6. Cast skills and confirm ascendancy notes/rules alter cast data.
7. Open Atlas Passives and allocate map reward nodes.
8. Run maps and check danger/reward shifts and extra materials/fragments.
