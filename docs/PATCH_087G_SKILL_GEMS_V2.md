# Patch 087G — Skill Gems V2: Active / Support / Spirit

This patch rebuilds the clean 3D project around the ARPG gem model instead of generic skill mods.

## Design

- Active Gems are actual castable skills.
- Support Gems modify an active gem when tags match.
- Spirit Gems reserve Spirit and provide persistent bonuses/rules.
- Skills are managed in a dedicated loadout panel instead of item-socket chaos.

## Controls

- `K`: skill loadout panel
- `1-4`: select active slot
- `Left Click` / `Space`: cast selected active slot
- `Q/R`: cycle active slot
- `Z/X`: health/mana flasks
- `I`: inventory
- `C`: character
- `M`: maps
- `E/T`: map/portal

## First Gems

Active: Fireball, Storm Lance, Arc Slash, Void Rift, Ember Mine.

Support: Controlled Power, Efficient Casting, Greater Area, Split Projectile, Chain Current, Ignition, Bleed Edge, Echoing Void.

Spirit: Clarity, Vitality, Ember Pact, Storm Rhythm, Void Tithe, Iron Skin.
