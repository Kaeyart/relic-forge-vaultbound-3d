# 087R — Final Greybox ARPG UI Suite

This patch replaces the stopgap UI with a proper pre-art ARPG UX shell.

## Main additions
- `GameHUD3D`: player resources, skill bar, flasks, quick panel buttons.
- `UIPanelRoot3D`: modal overlay, tab navigation, central panel frame.
- Inventory/equipment panel with drag/drop item slots.
- Forge panel with item input slot, action selection, material readout.
- Skill gem panel with active slots, support sockets, active/support gem libraries, spirit toggles.
- Map device panel with map stash, map input slot, map details, start/re-enter controls.
- Character panel with stat cards and equipment summary.

## Rule
This is not final art. It is the final greybox layout and interaction model.
