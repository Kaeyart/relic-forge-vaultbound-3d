# 096B — Hub Greybox Art Pass

## Goal

Make the hub readable and staged before real assets exist.

## Adds

- `scripts/visual/HubGreyboxPass3D.gd`

## Patches

- `scripts/core/GameRoot3D.gd`

The patch creates a runtime child:

`HubGreyboxPass096B`

## Visual language

- Stash becomes a vault chest silhouette.
- Forge becomes a furnace/anvil silhouette.
- Map Device becomes a portal gate.
- Gems become a crystal altar.
- Character becomes a shrine/stat obelisk.
- Descent becomes a major gate.
- Paths, plinths, labels, and colored lights make every function readable.

No external assets are used.
