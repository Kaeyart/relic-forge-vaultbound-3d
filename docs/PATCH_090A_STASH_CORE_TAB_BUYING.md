# 090A — Stash Core + Tab Buying

Adds the first real stash system.

Implemented:
- stash categories
- buyable stash tabs with gold
- tab customization: name, icon, color, affinity
- current-tab search and whole-stash search
- inventory Deposit routes selected item into stash
- withdraw stash item back into inventory
- base affinity routing for currency, maps, gems, crystals, and uniques
- Stash tab in the global UI panel root

Specialized tab layouts are still greybox. The next passes can make Currency, Maps, Gems, Crystals, and Uniques look like dedicated collection tabs instead of generic item grids.
