# 089A — Skill Gem Panel Rebuild

Adds the first real active/support/spirit gem loadout UI.

- Skills panel uses the left half of the screen.
- Active skill gems appear as large slots on the far-left.
- Active gems carry level, XP, quality, and socketed supports.
- Active gems start with 2 support sockets.
- Every 5 skill levels unlocks +1 socket, up to 6.
- Support sockets show empty, filled, and locked states.
- Spirit gems can be toggled on/off by right-click.
- Spirit reservation increases with supports.
- Gem stash sections exist for active/support/spirit gems.
- Dragging an active gem to stash keeps supports/level/xp/quality together.

Inventory right-click gem install is intentionally left for the next patch.
