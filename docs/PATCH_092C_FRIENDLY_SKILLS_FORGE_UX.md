# 092C — Friendly Skill Gems + Forge UX Pass

This patch makes the Skill Gems and Forge panels easier to understand without final art.

Skill Gems:
- selected active skill detail
- active gem level / XP / quality
- unlocked support sockets
- socketed support gems
- dictionary or legacy string support gem handling
- spirit reservation overview
- loadout overview

Forge:
- selected item detail
- readable item formatting through `UIItemFormatSystem3D.gd`
- currency summary
- operation/forge-potential preview guidance
- clear workbench instructions

This patch is presentation/UX only. It does not replace the underlying skill or crafting mechanics.
