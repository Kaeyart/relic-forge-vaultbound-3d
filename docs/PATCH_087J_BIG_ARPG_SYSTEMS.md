# Patch 087J — Big 3D ARPG Systems Pass

This combined patch deliberately bundles the systems that would otherwise have been separate small patches:

- physical 3D loot
- pickup pet
- boss reward presentation
- support/spirit gem drops and cleaner skill loadout controls
- crafting V2 starter forge actions
- map items and map modifiers
- class identity stat application
- strict itemization/equipment continuation

The goal is to make the 3D project feel like an ARPG loop instead of a combat test.

## Main Loop

Hub → start map → kill packs/boss → visible loot → pet collects currency/materials → manually pick gear/gems/maps → return hub → equip/craft/manage → run next map.

## Controls

- WASD/arrows: move
- Left Click / Space: cast selected skill
- 1–4: select active skill slot
- Q/R: cycle skill slot
- Z/X: health/mana flask
- E: pickup nearby loot / exit cleared map
- T: start map from hub / return to hub from combat
- I: inventory
- K: skills
- F: forge
- M: maps
- C: character
- H: help
- [ / ]: inventory or map cursor
- U: equip selected backpack item
- In Skills panel: A/D changes active gem, S adds support, W removes support, G toggles spirit gem
- In Forge panel: 1 Seal, 2 Reforge, 3 Polish
